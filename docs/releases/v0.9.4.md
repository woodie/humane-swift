# humane-swift v0.9.4

## Shared Finder-confirmed size fixtures

No behavior change: `Humane.humanSize` calls `ByteCountFormatter` directly,
so it already matched Finder. This release adds the 14 sizes confirmed
against real Finder output in
[humane#3](https://github.com/woodie/humane/issues/3) to `HumanSizeSpec`,
so all four `humane` libraries now test one shared set of sizes, and this
suite checks them against the real formatter on every CI run.

Released alongside `humane` v0.9.6, `humane-ruby` v0.9.4 and
`humane-kotlin` v0.1.2, which fix their hand-written ports to match.
